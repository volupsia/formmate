## Description
Learn how to build a complete full-stack React application using FormCMS and Cursor AI — without writing a single line of backend code.

In this tutorial you'll see how to:
✅ Start the FormCMS backend with a single Docker command
✅ Set up the admin portal and generate an API key
✅ Connect Cursor AI to FormCMS by creating .cursor/mcp.json in your project root with the MCP server URL and your API key
✅ Download the FormCMS skill rules file into .cursor/rules so Cursor understands your schema and APIs
✅ Scaffold a full Vite + React project with one Cursor chat prompt — schema, data, proxy config, and dev server all handled automatically
✅ Build frontend components (PostList, PostDetail) with zero manual schema lookup — Cursor reads them from MCP tools
✅ Deploy your SPA as the home page using the deploy_spa MCP tool — all from a single container

No manual backend work. No API wiring. Just describe what you want and let Cursor handle the rest.

🔗 FormCMS: https://github.com/formcms/formcms
🔗 Cursor AI: https://cursor.com
