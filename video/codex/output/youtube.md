## Description
Learn how to build a complete full-stack React application using FormCMS and VS Code with Codex — without writing a single line of backend code.

In this tutorial you'll see how to:
✅ Start the FormCMS backend with a single Docker command
✅ Set up the admin portal and generate an API key
✅ Connect VS Code Codex to FormCMS by configuring ~/.codex/config.toml with the MCP server and your API key
✅ Download the FormCMS AI instruction file so Codex understands your schema and APIs
✅ Scaffold a full Vite + React project with one Codex prompt — schema, data, proxy config, and dev server all handled automatically
✅ Build frontend components (PostList, PostDetail) with zero manual schema lookup — Codex reads them from MCP tools
✅ Deploy your SPA as the home page using the deploy_spa MCP tool — all from a single container

No manual backend work. No API wiring. Just describe what you want and let Codex handle the rest.

🔗 VS Code Codex: https://marketplace.visualstudio.com/items?itemName=GitHub.copilot
