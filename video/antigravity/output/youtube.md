## Description
Learn how to build a complete full-stack React application using FormCMS and the Antigravity IDE AI agent — without writing a single line of backend code.

In this tutorial you'll see how to:
✅ Start the FormCMS backend with a single Docker command
✅ Set up the admin portal and generate an API key
✅ Connect the Antigravity IDE AI agent to FormCMS via the built-in MCP server
✅ Download the FormCMS AI skill file to teach your agent the APIs
✅ Scaffold a full Vite + React project with one chat prompt — schema, data, proxy config, and dev server all handled automatically
✅ Build frontend components (PostList, PostDetail) with zero manual schema lookup
✅ Deploy your SPA as the home page using the deploy_spa MCP tool — all from a single container

No manual backend work. No API wiring. Just describe what you want and let the AI agent handle the rest.

🔗 FormCMS: https://github.com/formcms/formcms
🔗 Antigravity IDE: https://antigravity.dev
